# 주고받는 내용

`/room/<코드>?key=<열쇠>` 로 WebSocket 을 열어요. 코드는 대문자와 숫자 4~8자예요. 측정할 때만 `&hint=apac-ne` 로 방이 처음 생길 위치를 지정해요. 메시지는 지금 JSON 이고, 동작을 확인한 뒤 숫자만 담는 형식으로 줄일 수 있어요.

## 화면이 보내는 것

| `t` | 내용 |
| --- | --- |
| `join` | `name` 처음 입장, `token` 끊겼다 돌아올 때 |
| `start` | 방장만 보낼 수 있어요. 3초 뒤 시작해요 |
| `side` | `side` `cop`, `any`, `rob`. 칸이 바뀔 때만 보내요 |
| `seats` | 방장만. `cops`, `robs`, `bots`, `open` 공개 방, `shrink` 구역 축소, `mode` 놀이 방식(`classic`, `zombie`), `balance` 좀비 모드 판 균형(`surv`, `even`, `zomb`). 합쳐서 8명까지. `open`, `shrink`, `mode`, `balance` 를 빼면 그대로 둬요. 좀비 모드에서 `cops + robs` 는 방 인원이고 칸(`side`)은 생김새(고양이, 쥐)만 골라 인원 제한이 없어요 |
| `say` | `i` 정해진 말 번호 |
| `input` | `x`, `y` -1~1 이동, `s` 달리기, `c` 잡기. 초당 20번을 넘으면 버려요 |
| `ping` | `n` 지연 측정, `rtt` 직전에 잰 왕복 시간(ms, 판 결과에 사람별로 남아요) |
| `where` | 들어온 곳과 방 서버 위치 묻기 |

200자를 넘는 메시지는 버려요.

## 서버가 보내는 것

| `t` | 내용 |
| --- | --- |
| `joined` | `token` 돌아올 때 쓰는 값 |
| `lobby` | `players` 명단(`id`, `name`, `side`), `you`, `host` 내가 방장인지, `cops`, `robs`, `bots`, `open`, `shrink`, `mode`, `balance`, `max` |
| `count` | `ms` 시작까지 남은 시간 |
| `say` | `id` 말한 사람, `i` 정해진 말 번호 |
| `start` | `seed` 같은 지도를 만드는 값, `scale` 지도 크기(인원 4명까지 1, 8명이면 1.2), `theme`, `you` 내 캐릭터 번호, `team`, `wait`, `duration`, `police`, `robbers` 판의 인원, `rescue`, `autoEscape`, `catchRange`, `reveal` 이 판의 규칙 값, `intro` 판 시작 멈춤 초(역할 배너가 뜨는 동안 아무도 못 움직이고 시계도 안 가요), `shrink` 구역 축소 판인지. 축소 시각과 크기는 화면이 같은 값으로 `newGame` 을 불러 직접 얻어요(`docs/shrink.md`). 좀비 판은 `mode: "zombie"`, `balance`, `look` 내 생김새, `wait` 좀비가 깨어나는 초, `firsts` 뽑힌 좀비 이름(대기실 조명 뽑기용)을 더 실어요. 좀비 판의 `intro` 는 뽑기 장면만큼 2.4초 길어요. `team` 은 좀비가 `police`, 생존자가 `robber` 예요(`docs/zombie.md`) |
| `s` | 갱신. `time`, `phase`, `intro` 남은 시작 멈춤(멈춤 동안만), `me`(도둑은 `out` 구역 밖에 있은 초), `others`, `pings`, `rescue`, `nextReveal`, `freeRobbers`, 경찰은 `intel`. 좀비 판은 `van` 내가 아는 정류장(`x`, `y`, `open` 서는 시각, `close` 떠나는 시각), `escaped` 탄 사람 수, 생존자 `me.heart` 가장 가까운 좀비까지 0~3 단계, `me.board` 타는 중인 초. 상대(`others`)는 편과 생김새가 다르면 `look` |
| `e` | 사건 목록. 위치는 싣지 않아요. 구역 밖 공개가 시작되면 `outReveal`(`r` 그 도둑) 한 번. 구역 축소 판은 경계가 줄기 시작할 때 `shrink`(`n` 몇 번째). 좀비 판은 `bitten`(`r` 물린 사람, `by`), `turned`(`r` 좀비가 됨), `boarded`(`r` 구조차에 탐), `vanRadio`(생존자에게만), `vanOpen`, `vanLeave` |
| `over` | `winner`, `reason`, `stats`, `mine` 내 기록, `mvp` 팀별 MVP `{ police: {id, name}, robber: {id, name} }`(후보가 없는 팀은 `null`) |
| `pong` | `n` |
| `where` | `entry` 들어온 Cloudflare 위치, `room` 방 서버 위치 |
| `error` | `code`: `notHost`, `playing`, `full`, `sideFull`(`side` 내 칸), `cantStart` |

## MVP 정하는 법

판이 끝나면 서버가 팀마다 한 명을 골라 `over` 에 실어요(`shared/logic.js` `pickMvp`). 화면은 따로 계산하지 않아요.

- 경찰: 잡은 횟수가 많은 순, 같으면 많이 움직인 순, 그래도 같으면 먼저 들어온 순
- 도둑: 잡힌 횟수가 적은 순, 끝났을 때 감옥 밖, 구해 준 동료 수, 숨어 있던 시간, 많이 움직인 순, 먼저 들어온 순
- 좀비 판은 `police` 자리에 좀비 MVP(감염시킨 수가 많은 순, 많이 움직인 순), `robber` 자리에 생존자 MVP(먼저 탄 순, 물리지 않은 사람, 오래 버틴 순)가 와요. 생존자로 시작한 사람만 생존자 후보예요
- 사람이 두 명 이상인 판은 사람만 후보예요. 혼자 하기는 봇도 후보예요. 후보가 없는 팀은 무대를 건너뛰어요

## 열린 방 목록

`GET /rooms?key=<열쇠>` 는 공개 방 목록을 JSON 으로 돌려줘요. `rooms` 안에 `code`, `host` 방장 이름, `n` 들어온 사람, `max` 자리, `state` `open`/`full`/`playing`. 모집 중인 방이 먼저 오고 30개까지예요.

- 방은 처음에 비밀 방이에요. 방장이 공개로 바꾼 방만 목록 서버(`Directory`)에 알려요. 비밀 방은 아무것도 보내지 않아 목록에 나오지 않아요
- 방은 사람이 들고 날 때, 판이 시작하고 끝날 때, 공개를 바꿀 때만 알리고, 바뀐 게 없으면 보내지 않아요. 그 사이에는 2분마다 살아 있다고만 알려요
- 목록 서버는 5분 동안 소식이 없는 방을 지워요. 서버가 다시 떠서 방이 알리지 못한 경우를 위한 거예요
- 입구는 같은 서버 안에서 4초 동안 같은 목록을 나눠 써요. 화면은 목록을 보는 동안 5초마다 받아 와요

## 운영 상태

`GET /live` 는 지금 도는 판 수를 `{ playing, until }` 으로 돌려줘요(`until` 은 늦어도 끝나는 때). 자동 배포가 판이 끝날 때까지 기다리는 데 써요. 방이 판을 시작하고 끝낼 때 운영 상태 서버에 알리고, 알리지 못하고 사라진 방은 만료 시각이 지나면 세지 않아요. 입구가 4초 동안 같은 값을 나눠 써요.

`GET /status` 는 누구나 읽어요. `{ mode, message, until }`. `mode` 는 `open`(누구나), `soon`(공개 전, 열쇠가 있는 사람만), `pause`(점검 중, 아무도 새로 못 들어옴). 첫 화면이 이 값으로 공개 전 화면, 점검 화면, 첫 화면을 골라요. 바꾸는 법은 `docs/ops.md`.
