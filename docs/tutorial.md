# 하는 방법 안내

> 2026-11-13: 첫 화면의 "게임 방법"은 이 문서의 작은 무대 대신 실제 게임 엔진으로 장면을 연기시키는 방식으로 만들었어요(`docs/guide.md`). 아래 규칙 표의 시간 값은 판 설정의 기록이고, 사용자에게 보이는 안내에는 초를 적지 않아요.

처음 온 사람이 대기실에서 기다리는 동안, 게임 부품(조이스틱, 버튼, 냥파, 도둥이)이 직접 움직이는 짧은 장면으로 하는 법을 보여 줘요. 영상 파일은 쓰지 않아요.

## 우리 게임 규칙 (사람끼리 하는 판, 2026-11-06 코드 기준)

| 규칙 | 값 | 코드 |
| --- | --- | --- |
| 판 길이 | 시작 대기 15초 뒤 3분 | `WAIT_SEC`, `GAME_SEC` |
| 경찰 출동 | 대기 동안 경찰은 감옥 앞에서 기다리고 도둑만 흩어져요 | `state: "waiting"` |
| 시야 | 앞쪽 부채꼴과 바로 주변만 보여요. 수풀 안 상대는 아주 가까이 와야 보여요 | `VISION`, `BUSH_SEE` |
| 달리기 | 빨라지지만 막대가 닳아요. 다 닳면 회복될 때까지 못 달려요 | `STAMINA`, `REGEN` |
| 잡기 | 경찰 가까이 있는 도둑을 잡아요. 잡을 수 있으면 도둑 발밑에 노란 표시가 떠요 | `CATCH_R`, `CATCH_ASSIST` |
| 위치 공개 | 35초마다 자유로운 도둑 위치가 경찰 지도에 4초 동안 떠요 | `REVEAL_SEC`, `REVEAL_SHOW` |
| 감옥 | 잡힌 도둑은 가운데 감옥으로 가요. 저절로 나오지 않아요 | `AUTO_ESCAPE: false` |
| 구출 | 같은 편 도둑이 감옥 앞에 1.2초 서 있으면 문이 열리고, 나와서 3초 동안 안 잡히면 다시 자유예요 | `RESCUE_SEC`, `BREAK_SEC` |
| 승패 | 경찰은 도둑을 모두 감옥에 보내면, 도둑은 시간이 끝날 때까지 다 잡히지 않으면 이겨요 | `allArrested`, `timeUp` |

## 근거

- 튜토리얼의 효과는 게임 복잡도에 달려 있어요. 4만 5천 명을 나눠 본 연구에서, 해 보면 알 수 있는 단순한 게임은 튜토리얼이 참여를 크게 늘리지 않았고, 복잡한 게임에서는 플레이 시간을 최대 29% 늘렸어요 (Andersen 외, CHI 2012, https://grail.cs.washington.edu/projects/game-abtesting/chi2012/). 그래서 **해 보면 아는 것(걷기)은 짧게, 해 봐도 모르는 규칙(구출, 위치 공개, 잡기 범위)에 장면을 더 써요**
- 글로 된 투어와 오버레이는 넘겨 버리기 쉽고, 해 보게 하거나 보여 주고, 글은 행동을 이끄는 한 줄로 쓰는 쪽이 낫다고 해요. 한꺼번에 몰아 주지 말고 필요할 때 나눠 줘요 (Smashing Magazine, 2014, https://www.smashingmagazine.com/2014/04/rethinking-mobile-tutorials-which-patterns-really-work/)
- skribbl.io 는 첫 화면에 "How to play" 다섯 단계를 움직이는 그림과 한 줄 글로 보여 줘요 (https://skribbl.io/). 친구끼리 모이는 웹 파티 게임이 기다리는 자리에서 규칙을 보여 주는 같은 꼴이에요
- Brawl Stars 는 처음 할 때 짧은 필수 튜토리얼로 왼쪽 이동 조이스틱과 오른쪽 공격을 가르쳐요 (https://www.pocketgamer.com/brawl-stars/brawl-stars-tips-and-tricks-a-guide-for-the-beginner-brawler/). 우리도 실제 버튼 자리에서 손가락이 움직이게 해요

## 정한 것

| 결정 | 이유 |
| --- | --- |
| 대기실에서 보여 줘요. 게임 중에는 띄우지 않아요 | 친구를 기다리는 시간이라 막는 게 없어요. 게임 중에는 이미 있는 짧은 알림(노란 표시, "같은 편이 감옥 앞에 오면") 이 그 자리에서 알려 줘요 |
| 처음 한 번 저절로 열리고, "하는 방법" 버튼으로 다시 봐요 | 앞에 몰아 주지 않되 처음 온 사람이 놓치지 않게 해요 |
| 편마다 네 장면, 장면당 2~3초, 한 줄 글 | 한 장면에 하나만 보여 줘요. 내가 고른 편을 먼저 보여 줘요 |
| 실제 부품이 움직여요 | 본 그대로 바로 따라 할 수 있고, 버튼 자리를 바꾸면 안내도 같이 바뀌어요 |
| 폰은 손가락, PC 는 키 모양이 눌려요 | 각자 쓰는 조작으로 보여 줘요 |
| 저절로 넘어가고, 누르면 바로 다음, 언제든 닫기 | 아는 사람은 빨리 넘기고, 모르는 사람은 끝까지 봐요 |
