# 좀비 모드

방장이 놀이 방식으로 고르는 두 번째 판이에요. 한 명이 좀비로 시작하고, 물린 사람은 좀비 편이 돼요. 한 명이라도 구조차를 타면 생존자가 이겨요. 규칙은 `shared/logic.js` 의 `CFG.ZOMBIE`, `vanPlan`, `updateVan`, `bite`, `turn`, 서버는 `server/room.ts` `beginZombie`.

## 편과 생김새

- 좀비는 잡는 편(`team: "police"`), 생존자는 도망치는 편(`team: "robber"`)에 얹었어요. 잡기, 위치 공개, 시야, 봇을 그대로 써요
- 생김새(고양이, 쥐)는 편과 따로 `look` 에 둬요. 대기실 칸이 생김새를 정하고(고양이로, 아무나, 쥐로), 편은 시작할 때 정해져요
- 물리면 2초(`TURN`) 비틀거리다 좀비 편으로 옮겨요. 생김새는 그대로예요. 문 좀비는 2초(`BITE_HOLD`) 그 자리에 멈춰서 옆 사람이 도망칠 틈이 생겨요

## 첫 좀비

- 사람 중에서 무작위로 뽑아요. 지난 좀비 판에 첫 좀비였던 사람은 빼요(다 빠지면 모두 중에서). 접속에 `firstZ` 로 남겨서 방이 잠들어도 기억해요
- 봇을 끈 판은 적어도 한 명이 생존자로 남아요
- 첫 좀비 수는 `zombieFirst(인원, 판 균형)`. 지금은 세 단계 모두 한 명이에요(봇 판에서 둘이면 좀비가 90% 넘게 이겼어요)

## 움직임과 감각

| | 생존자 | 좀비 |
| --- | --- | --- |
| 걷기 | 230 | 판 균형(반반 212), 첫 좀비가 혼자일 때 236 |
| 달리기 | 316, 체력 3.4초 | 생존자와 같아요 |
| 감각 | 안 보이는 좀비가 300 안이면 심장 소리 세 단계(`me.heart`) | 판 균형 간격(반반 45초)마다 생존자 위치 4초 공개 |
| 버튼 | 달리기 | 물기(잡기와 같음) |

## 구조차

- 끝나기 50초 전(`VAN_AT`)부터 물결로 서요. 반반은 두 곳, 20초 뒤 두 곳 더
- 자리는 무전 때 그 순간 좀비들에게서 가장 먼 큰길 위로 골라요. 서로 700 넘게 떨어져요
- 생존자는 무전(반반 20초 먼저)으로 미리 알고, 좀비는 차가 선 뒤에 알아요(`view.van`, `vanRadio` 는 생존자에게만)
- 차 옆 110 안에서 버티면(반반 1초) 타요. 칸을 벗어나거나 물리면 처음부터예요. 탄 사람은 지도에서 빠지고 안전해요
- 생존자가 한 명만 남으면 그때부터 판 균형 초(반반 20초) 뒤에 정류장이 하나 열려요

## 승패

- 한 명이라도 타면 생존자 승리(`escaped`). 판은 남은 생존자가 모두 타거나 물릴 때까지, 아니면 끝날 때까지 가요
- 아무도 못 타고 모두 물리면 `allInfected`, 시간이 다 되면 `noEscape` 로 좀비 승리

## 판 균형

| | 생존자 쪽 | 반반 | 좀비 쪽 |
| --- | --- | --- | --- |
| 좀비 걷기 (혼자일 때) | 205 (230) | 212 (236) | 220 (244) |
| 위치 공개 | 55초 | 45초 | 35초 |
| 깨어나는 시간 | 15초 | 12초 | 10초 |
| 무전 | 25초 먼저 | 20초 먼저 | 12초 먼저 |
| 정류장 | 세 곳, 20초 뒤 한 곳 더 | 두 곳, 20초 뒤 두 곳 더 | 한 곳씩 두 번 |
| 타는 시간 | 1초 | 1초 | 1.5초 |
| 혼자 남으면 | 15초 뒤 | 20초 뒤 | 30초 뒤 |

봇끼리 40판에서 좀비 승률은 6명(지도 1.1배) 기준 생존자 쪽 57%, 반반 73%, 좀비 쪽 85%였고, 반반은 4명 75%, 8명(지도 1.2배) 53%였어요. 봇 생존자는 사람보다 피하는 게 서툴러서 실제로는 생존자 쪽으로 기울 거라고 보고, 사람끼리 해 본 뒤 `CFG.ZOMBIE.BAL` 의 걷기와 위치 공개부터 다시 맞춰요.

```bash
node tools/sim.mjs 40 '[[{"mode":"zombie","balance":"even","police":1,"robbers":5,"scale":1.1},"반반 6명"]]'
```

| 자리 | 좀비 판 |

| 걸음 | 좀비는 `shambleSide`, `shambleFront`(`playground.html`): 팔을 앞으로 짧게 뻗고 발을 끌며 절뚝여요. 달리면 박자가 빨라져요. 고양이 옆모습은 원래 팔이 몸에 붙어 있어 앞으로 뻗은 팔을 덧그리고, 곤봉과 자루는 숨겨요 |
| 물기 | 옆모습으로 돌아 앞으로 덮쳐요. 물린 사람은 2초 비틀거리며 색이 빠지다 좀비 그림으로 다시 만들어지고 보라 가루가 피어요 |
| 지도 | 감옥 자리는 광장 바닥만 남겨요 |
| 위 칸 | 점은 노랑 생존자, 테두리 노랑 탄 사람, 보라 좀비. 좀비는 "생존자 위치 공개", 생존자는 "내 위치 공개"였다가 무전 뒤 "구조차 오기까지 / 떠나기까지 / 섰어요" |
| 구조차 | 길 폭에 맞춘 노란 칸(서기 전엔 점선)과 노란 구조차(경찰차 그림의 파랑을 노랑으로), 미니맵에 노란 칸, 타는 중이면 머리 위 원 |
| 심장 소리 | 안 보이는 좀비가 300 안이면 세 단계로 가장자리가 붉게 뛰고 심장 소리 |
| 버튼 | 좀비는 "물기", 생존자는 달리기만. 내가 물려 좀비가 되면 버튼과 색이 바로 바뀌어요 |
| 장면 | 역할 배너 두 줄(좀비 보라 띠, 생존자 흰 띠), 좀비 대기(달밤, 지붕 그림자, 안개, 휘청이며 지나가는 좀비), 깨어나기 카운팅(초승달, 보라·연두 빛, "깨어났어요!"), 물린 순간, MVP(좀비 보라 무대와 반딧불, 생존자 노랑 무대) |

## 모드 고르기와 대기실 (`client/modes.js`, `client/solo.js`, `client/lobby.js`)

- 홈의 혼자 해 보기와 방 만들기는 먼저 모드 카드 두 장(경찰과 도둑, 좀비 모드)을 열어요. 카드는 바탕 하나에 캐릭터, 이름과 한 줄, 판 길이·인원, 배지 세 개와 내 기록이에요. 기록과 배지는 이 폰에만 남기고(`localStorage` 의 `modes:`), 마지막에 고른 모드를 기억해요. 처음 보는 모드에는 NEW
  - 배지: 경찰과 도둑은 첫 승리, 한 판에 3명 잡기, 도둑으로 끝까지. 좀비 모드는 첫 탈출, 한 판에 4명 감염, 물리지 않고 끝내기
- 방 만들기에서 좀비 모드를 고르면 주소에 `mode=zombie` 를 실어 방을 열고, 방장이 대기실에 들어가며 방 설정을 한 번 보내요
- 혼자 하기: 좀비 모드면 위 칸이 내 역할(좀비 / 생존자 / 무작위, 이름만)과 판 균형(생존자 쪽 / 반반 / 좀비 쪽)이에요. 제목 옆 모드 칩을 누르면 모드 카드로 돌아가요. 주소 `game.html?mode=zombie&balance=even` 으로도 열려요
- 대기실: 방 코드 칸에 "좀비 모드", 방 설정 맨 위에 놀이 방식, 좀비 모드는 인원 한 칸과 판 균형. 칸은 생김새만 고르니 인원 제한 없이 사람 수만 보여요. 안내 줄, 정해진 말이 모드를 따라 바뀌고, 방장이 놀이 방식을 바꾸면 모두에게 알려요. 시작 버튼 위에 "시작하면 좀비를 뽑아요"
- 좀비 뽑기: 시작 신호(`firsts`)를 받으면 대기실 불이 꺼지고, 위에서 내리꽂는 탐조등이 사람들 사이를 옮겨 다니다 점점 느려져요. 뽑힌 사람 옆에 한 번 들렀다 돌아와 멈추고, 형광등처럼 두어 번 깜빡인 뒤 초록 빛으로 바뀌며 그 사람이 좀비 모습이 돼요("오늘 밤 좀비는 ○○"). 모두 약 5초이고 서버는 그만큼 시작 멈춤을 늘려 둬요(`ZOMBIE_DRAW_SEC`). 움직임 줄이기를 켠 폰은 옮겨 다니지 않고 바로 멈춰요
- 공터: 버려진 주차장이에요. 갈라진 아스팔트, 지워진 주차선, 웅덩이, 한쪽 발을 끌고 지나간 발자국, 찢어진 철망과 출입 금지 띠, 깜빡이는 가로등 빛, 수풀에서 가끔 반짝이는 눈. 무섭되 피나 상처는 그리지 않아요
- 화면 문구에서는 판을 시작하는 좀비를 "첫 좀비"가 아니라 "좀비"라고 불러요
