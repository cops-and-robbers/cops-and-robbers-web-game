# 소리

사운드 담당도 예산도 없어서, 상업적으로 써도 되는 CC0 효과음을 고르고 다듬어 써요. 소리는 꼭 필요한 순간에만 내요.

## 원칙

- 내 상황이 바뀌는 순간에만 소리를 내요. 화면으로 이미 충분히 보이는 건 소리를 겹치지 않아요
- 같은 소리 사이에 최소 간격을 둬요(`SOUND_MIX`). 연달아 나면 시끄럽고 의미가 흐려져요
- 같은 소리가 매번 똑같이 들리지 않게 크기를 ±10% 흔들어요. 자주 반복되는 심장, 헛손질, 시계는 높이도 ±4% 흔들어요. 멜로디가 있는 소리는 흔들면 음이 틀어져 들려서 높이는 그대로 둬요
- 보이는 상대에 대해서만 소리를 내요. 안 보이는 상대의 정보가 소리로 새지 않아요
- 진동은 앱의 `vibration_patterns.dart` 값을 그대로 써요(체포 500ms, 위치 공개 250ms, 출동 경찰 짧게 두 번, 도둑 길게 한 번)

## 순간

| 소리 | 듣는 사람 | 언제 |
| --- | --- | --- |
| `spotted` | 도둑 | 5초 넘게 못 보던 경찰이 시야에 들어온 순간 |
| `heart` | 도둑 | 경찰이 보이는 동안. 가까울수록 빨리 |
| `found` | 경찰 | 5초 넘게 못 보던 도둑이 시야에 들어온 순간 |
| `catch`, `caught`, `miss` | 잡은 경찰, 잡힌 도둑, 놓친 경찰 | 잡기 결과 |
| `reveal` | 경찰, 자유로운 도둑 | 위치 공개 |
| `free` | 풀려난 도둑과 같은 편 | 감옥 문이 열림 |
| `go` | 모두 | 경찰 출동 |
| `alert` | 경찰 | 감옥 문이 열리는 중(처음 한 번) |
| `tick` | 모두 | 마지막 5초 |
| `win`, `lose` | 모두 | 결과 |

뺀 것: 조준음, 추격 북소리, 웅웅거림, 수풀 안 먹먹함, 공개 5초 전 째깍. 화면에 이미 보이거나 너무 자주 나서 오히려 방해가 됐어요.

## 고른 소리

처음엔 앱 버튼용 효과음(Kenney Interface Sounds, UI Audio)을 다듬어 썼는데, 게임보다 앱 알림처럼 들렸어요. 그래서 게임용 묶음으로 다시 골랐어요. 들어 볼 수 없는 자리에서 고르느라 음 높이 흐름(오르나 내리나), 타격 수, 밝기, 길이를 숫자로 재서 순간의 뜻과 맞췄어요.

| 소리 | 재료 | 고른 이유 |
| --- | --- | --- |
| `spotted` | 둔탁한 쿵 + 반음씩 오르는 피치카토, 세 반음 낮춤 | 살금살금 다니다 들킨 느낌. 피치카토는 "몰래" 장면에 흔히 쓰는 악기예요 |
| `heart` | 심장 한 번 | 그대로 |
| `found` | 피치카토 5도 위로 한 번 | 짧게 "찾았다". 자주 나서 가볍게 |
| `catch` | 수갑 딸깍 + 오르는 네 음 | 잡는 순간을 수갑 소리로 |
| `caught` | 수갑 딸깍 + 쿵 + 내려가는 네 음 | 잡았다의 거울. 같은 순간을 반대편에서 들어요 |
| `miss` | 옷자락 휙 | 헛손질 |
| `reveal` | 스틸드럼 한 번 | 피치카토와 다른 악기라 "모두에게 알림"으로 구분돼요 |
| `free` | 문 열림 + 오르는 피치카토 | 감옥 문이 열리고 빠져나가요 |
| `go` | 사이렌 두 번 오르기 | 경찰 출동 |
| `alert` | 빠르게 내려가는 경보 두 번 | 출동 사이렌과 다른 모양이라 섞이지 않아요 |
| `tick` | 시계 딸깍 | 마지막 5초 |
| `win` | 스틸드럼 오르는 네 음 + 5도 울림 | 밝게 끝나요. 잡았다와 같은 흐름을 다른 악기로 크게 |
| `lose` | 색소폰이 반음씩 내려가는 네 음 | 아쉽지만 웃으며 끝나는 쪽 |

## 출처와 만드는 법

- 모두 CC0 라 공개 저장소에 그대로 둬도 돼요. Kenney Music Jingles, Impact Sounds, RPG Audio / OpenGameArt aquinn "Sirens and Alarm Noise" / BigSoundBank #0218 Heart beat. 자세한 건 `client/brand/sound/LICENSE.md`
- 앞뒤 무음을 자르고, 끝 6ms 만 줄여 딸깍 튀는 소리를 막아요. 파형 최고점을 -3 dBFS 로 맞춘 뒤 64kbps 모노 mp3 로 냈어요. 13개 합쳐 약 100KB
- 최고점이 같아도 귀에 들리는 크기는 달라요(사이렌이 잡기 소리보다 8dB 크게 들렸어요). 그래서 파일마다 LUFS 를 재서 `SOUND_MIX` 크기를 정했어요
- 파일을 다시 만들 때 Sonniss 같은 재배포 금지 묶음은 쓰지 않아요. 이 저장소는 공개라 소리 파일이 그대로 올라가요
