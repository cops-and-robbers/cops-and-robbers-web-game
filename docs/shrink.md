# 구역 축소

방장이 켜는 방 옵션이에요. 켜면 판 동안 구역이 네 번 줄어들고, 배그의 자기장처럼 다음 구역을 미리 보여 줘요. 규칙은 `shared/logic.js` 의 `CFG.SHRINK`, `shrinkPlan`, `shrinkState`, `inZoneNow`, 화면은 `client/zone.js`.

## 언제, 얼마나

앱 4.0.1 과 같은 공식이에요(`shrink_schedule.dart`). 첫 축소는 출동 뒤 한 간격, 간격은 (판 길이 - 경찰 대기) ÷ 5.

| 축소 | 판 시계 | 남은 시간 표시 | 크기(반경) |
| --- | --- | --- | --- |
| 1 | 0:48 | 2:12 | 100% → 92.5% |
| 2 | 1:21 | 1:39 | → 85% |
| 3 | 1:54 | 1:06 | → 77.5% |
| 4 | 2:27 | 0:33 | → 70% (마지막) |

- 처음 구역(물결 진 다각형)을 감옥 가운데로 줄여요. 감옥 문 둘레(구출 자리 + 160)는 늘 구역 안에 남아요
- 경계는 8초 동안 걸어 들어와요(`MOVE`). 앱은 한 번에 줄지만 온라인은 화면이 곧 몸이라 피할 시간을 줘요
- 시각과 크기는 판 시작에 모두 정해져요. 서버는 `start` 에 `shrink` 만 싣고, 화면은 같은 값으로 `newGame` 을 불러 같은 계획을 얻어요. 판 중에 보내는 메시지는 늘지 않아요(`tools/ruletest.mjs` 가 같은 계획인지 확인)

## 구역 밖

새 벌칙은 없어요. 있던 규칙을 줄어든 경계에 그대로 걸어요.

- 도둑: 지금 구역 밖에 5초 넘게 있으면 1초마다 경찰에게 위치가 보여요(`OUT_GRACE`)
- 경찰과 도둑 모두: 구역 밖에서는 상대가 안 보여요(`view.js canSee`, 화면 안개). 그래서 경찰도 구역에 묶여요
- 앱의 "경고 3번이면 자동 체포"는 가져오지 않았어요. 3분 판에서는 거의 안 일어나고 위치 공개가 같은 일을 해요

## 화면

같은 정보를 두 진영이 똑같이 봐요. 색 하나가 뜻 하나예요: 흰 선 = 다음 구역, 빨간 점선 = 지금 경계, 주황 = 곧 밖, 빨강 = 지금 밖.

| 순간 | 보이는 것 |
| --- | --- |
| 평소 | 다음 구역 흰 선(어두운 테), 지금 경계 빨간 점선, 미니맵 두 선, 미니맵 아래 "구역 축소 0:20" 칸과 네 칸 막대(판 전체 진행) |
| 10초 전 | 칸 숫자가 주황, 3초 전부터 빨강, 알림 "10초 뒤 구역이 줄어들어요", 알림 소리와 째깍 |
| 다음 구역 밖 | 내 둘레 주황 화살표가 가장 가까운 안쪽을 가리키고, 아래 칸이 주황 "흰 선 안으로 들어가요" |
| 줄어드는 중 | 빨간 점선이 흰 선까지 걸어오고 점선이 안쪽으로 흘러요. 칸은 "줄어드는 중 1/4" |
| 지금 밖 | 화살표 빨강, 화면 가장자리 붉은 빛(밖에 있은 시간만큼 진해지고 깜빡이지 않아요), 지금의 빨간 칸 |
| 줄어든 뒤 | "구역이 줄었어요 (1/4)", 마지막은 "마지막 구역이에요. 더 줄어들지 않아요"(앱 문구) |

## 정한 것

| 결정 | 이유 |
| --- | --- |
| 마지막 크기 70% (앱은 40%) | 봇끼리 125판(지도 다섯 종, 위치 공개 35초)에서 40% 는 경찰 100%, 60% 는 82%, 70% 는 54%, 축소 없는 판은 37%. 8명 판(경찰 3, 도둑 5)은 축소 없이 23%, 70% 면 53%. 온라인 지도는 시야가 구역에 비해 넓어 좁아질수록 경찰이 거의 다 봐요(사용자 판단, 2026-11-15) |
| 위치 공개를 늘려 보상하지 않음 | 60% 에 공개 50초를 더해도 77% 라 모자랐어요. 크기 한 값으로 맞춰요 |
| 위치 공개와 축소가 겹쳐도 그대로 | 35초 공개가 축소 시작 2~8초 뒤와 겹쳐요. 70% 수치는 겹친 채로 쟀어요(사용자 판단) |
| 남은 시간 칸은 미니맵 아래 | 화면 위 가운데는 남은 시간과 위치 공개 칸으로 찼어요. 배그처럼 미니맵에 붙여 두 칸이 다투지 않게 해요 |
| "곧 밖"은 주황, "지금 밖"은 빨강 | 아직 벌칙이 없는 상태를 벌칙과 같은 색으로 말하면 놀라기만 해요. 할 일(흰 선 안으로)만 말해요 |
| 지금 밖이면 붉은 막을 빼고 가장자리 빛만 | 밖은 이미 안개로 어두워서 막까지 겹치면 화면이 탁해요 |
| 혼자 하기는 처음에 꺼 둠 | 지금 판이 기본이에요. 켠 사람만 다음에도 켜진 채로 열려요(`localStorage` 의 `solo:shrink`) |

## 봇

- 도둑: 다음 축소까지 22초 안쪽이거나 줄어드는 중이면 다음 구역 안의 숨을 곳만 골라요. 숨은 자리가 다음 구역 밖이면 옮겨요
- 경찰: 지금 구역 안의 숨을 곳을 돌아봐요

## 수치 다시 재기

`CFG.SHRINK.FINAL` 한 값만 바꿔요. `balance-check` 스킬대로 `tools/sim.mjs` 에 `shrink: true` 와 `reveal: 35` 를 넣어 전후를 견주고, 사람끼리 해 본 결과를 더 믿어요.

```bash
node tools/sim.mjs 60 '[[{"theme":"town","reveal":35},"기본"],[{"theme":"town","reveal":35,"shrink":true},"축소"]]'
```
