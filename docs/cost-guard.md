# 비용 지키기

**돈이 나가면 안 돼요.** 올리기 전에 이 문서를 확인해요.

## 무료 한도 (Durable Objects, Workers 무료 요금제)

| 항목 | 하루 한도 | 넘으면 |
| --- | --- | --- |
| 요청 | 100,000건 | 오류로 막혀요. 오전 9시(UTC 0시)에 풀려요 |
| 실행량 | 13,000 GB-s | 위와 같아요 |

- 받는 WebSocket 메시지는 20개를 1건으로 쳐요. 보내는 메시지는 무료예요
- 무료 요금제는 한도를 넘어도 청구되지 않고 막혀요. **유료 요금제(Workers Paid)면 넘은 만큼 청구되니, 올리기 전에 요금제를 꼭 확인해요**
- 공식 문서: https://developers.cloudflare.com/durable-objects/platform/pricing/

## 한 판의 계산

6명, 입력 초당 10번, 195초: 591건. 입력을 초당 4번으로 줄이면 240건이에요. 깨어 있는 시간은 한 판 195초라 하루 약 530판에서 차요.

## 코드에 있는 안전장치

| 장치 | 위치 |
| --- | --- |
| 열쇠가 없으면 방을 못 열어요. 열쇠 설정이 없으면 아무도 못 들어와요 | `server/index.ts` |
| 허용한 사이트에서만 브라우저 접속을 받아요 | `server/index.ts` |
| 입력 초당 20번 초과와 200자 초과는 버려요 | `server/room.ts` |
| 방 하나 6명까지 | `server/room.ts` |
| 정해진 시간을 넘긴 판, 30초간 아무도 없는 판은 멈춰요 | `server/room.ts` |
| 대기 중에는 잠들어요 | `server/room.ts` |
| 검증 도구는 올린 서버에 4명, 초당 5번, 60초를 넘겨 보낼 수 없어요 | `tools/room-check.mjs` |
| CI 는 배포하지 않아요 | `.github/workflows/ci.yml` |

## 올릴 때

`safe-deploy` 스킬을 따라요. 공개 전 시험은 열쇠를 쓰고, 시험이 끝나면 서버를 지워요. 사용량은 시험 직후 Cloudflare 숫자로 확인해요. 공개는 팀 결정 후에 하고, 공개 전에 한도를 넘었을 때 혼자 하기로 넘기는 화면을 먼저 만들어요.
