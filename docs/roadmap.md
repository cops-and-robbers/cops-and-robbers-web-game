# 만드는 순서

| 단계 | 내용 | 넘어가는 기준 | 상태 |
| --- | --- | --- | --- |
| 1. 방 서버 | 입장, 판 진행, 시야 필터, 끊김, 비용 안전장치 | 가짜 접속으로 한 판이 끝까지 돌아요 | 내 컴퓨터 통과 |
| 2. 실제 서버 시험 | 열쇠를 건 채 아주 적은 트래픽으로 올려 지연과 사용량을 재요 | 잰 사용량이 계산과 맞아요 | 지연 통과, `pages.dev` 입구로 결정. 메시지 수 대조는 남음 |
| 3. 사람끼리 하는 화면 | 게임 화면이 서버가 보낸 것만 그리게 바꿔요 | 2~4명이 같은 방에서 끝까지 해요 | 다음 |
| 4. 대기실 | 방 코드, 초대 링크, 팀, 정해진 말 | 팀원이 설명 없이 들어와 시작해요 | |
| 5. 폰 통신 시험 | 데이터와 와이파이, 8명, 저가 폰, SKT 와 LG U+, 저녁 시간 | 조작이 밀리지 않아요 | |
| 6. 수치 조정 | 경찰 사거리, 인원 비율, 판 길이 | 사람끼리 해서 재밌어요 | |
| 7. 공개 | 공유 카드, 앱 받기, 신고, 한도 초과 처리, 사이트 연결 | 팀 결정 | |

## 처음에 넣지 않는 것

자유 채팅, 빠른 대전, 친구 목록, 랭킹, 계정. 자유 채팅은 신고와 욕설 처리, 약관까지 따라와요. 정해진 말로 부족하다는 얘기가 나오면 그때 정해요.

## 정하지 못한 것

- 게임 이름과 주소
- 사람끼리 경찰과 도둑 비율, 판 길이
- 부정행위와 신고 방식
- 닉네임과 접속 기록을 약관에 어떻게 맞출지
