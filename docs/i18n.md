# 언어 (한국어, 영어, 일본어)

화면 문구는 `client/i18n.js` 한 파일에 언어별로 있어요. 한국어가 원문이고, 영어와 일본어는 같은 키로 둬요.

## 언어를 정하는 순서

1. 주소의 `?lang=ko|en|ja`(내 컴퓨터 파일로 열 때 쓰는 길)
2. 언어 주소 `/en/play`, `/ja/play`. 웹사이트 영어, 일본어 페이지가 이 주소로 보내요
3. 게임 안에서 고른 언어. `localStorage` 의 `lang` 에 남아 다음에도 그 언어로 열려요
4. 브라우저 언어(`navigator.languages`). 앞 두 글자가 `ko`, `en`, `ja` 중 하나면 그 언어
5. 다 아니면 영어

주소로 고른 언어도 저장해요. 정해진 언어가 주소와 다르면 다시 열지 않고 주소만 그 언어 주소로 바꿔요(`/play` 를 연 일본어 브라우저는 `/ja/play`). 초대 링크가 지금 주소를 쓰니, 받은 친구도 보낸 사람 언어의 공유 카드를 봐요.

## 공유 카드(링크 미리보기)

카카오톡, 라인, 디스코드 같은 메신저는 스크립트를 돌리지 않고 문서 머리(`og:title`, `og:image`)를 그대로 읽어요. 그래서 언어마다 주소를 따로 둬요.

| 주소 | 카드 제목 | 그림 |
| --- | --- | --- |
| `/play` | 경찰과 도둑 온라인 게임 | `og.png` |
| `/en/play` | Cops and Robbers Online | `og-en.png` |
| `/ja/play` | ケイドロ オンライン | `og-ja.png` |

- 세 주소는 같은 화면이에요. `tools/build.py` 가 한국어 문서 머리만 그 언어로 바꿔 `gateway/public/en/play.html`, `ja/play.html` 을 만들어요. 머리 문구는 `build.py` 의 `HEAD` 에 있고 `i18n.js` 의 `title`, `desc`, `ogAlt` 와 같게 둬요
- 세 문서는 서로를 `hreflang` 으로 가리키고, `x-default` 는 `/play` 예요(브라우저 언어로 고르는 주소)
- 카드 그림은 한국어 그림과 같은 배경과 캐릭터에 글자 로고만 바꿨어요(1200x630)
- 카카오톡은 카드를 저장해 둬요. 처음 올린 뒤에는 카카오 공유 디버거에서 `/en/play`, `/ja/play` 캐시를 지워요

## 언어 고르기 화면

언어는 첫 화면 오른쪽 위와 초대받아 들어온 이름 입력 화면에서 바꿔요. 바꾸면 그 언어로 다시 열어요. 진행 중인 판이 없는 화면들이라 잃는 게 없어요.

| 정한 것 | 이유 |
| --- | --- |
| 지구본 아이콘과 지금 언어 이름(`English`), 국기는 쓰지 않음 | 국기는 나라를 뜻하고 언어는 나라를 넘어요. 지구본에 글자를 붙인 모양이 큰 사이트들의 흔한 방식이에요 |
| 언어 이름은 그 언어로(한국어, English, 日本語), 줄임말(EN) 쓰지 않음 | 모르는 언어 화면에서도 자기 언어를 찾을 수 있어요. 줄임말은 브라우저 자동 번역이 망가뜨리기 쉬워서 `translate="no"` 도 붙였어요 |
| 브라우저 선택 상자 대신 버튼 옆의 작은 메뉴 | 셋뿐이라 목록 화면이나 검색이 필요 없고, 화면을 덮지 않는 메뉴로 충분해요. 기본 선택 상자는 폰마다 모양이 달라 게임 화면과 어긋났어요 |
| 지금 언어는 체크와 옅은 파랑 바탕, 굵은 글씨 | 지금 무엇이 골라져 있는지 색 하나에 기대지 않고 보여요 |
| 줄 높이 48px, 버튼 누르는 자리 44px 이상 | 손가락으로 누르는 최소 크기(WCAG 2.5.5, Apple HIG 44pt) |
| 자동으로 고르되 저장된 선택이 먼저 | 브라우저 언어가 사람이 원하는 언어와 늘 같지는 않아요. 자동으로 열되 언제든 바꾸게 하고, 바꾼 건 기억해요 |
| 키보드: 화살표로 옮기고 Esc 로 닫으면 버튼으로 돌아옴. 각 언어 줄에 `lang` | 읽어 주는 프로그램이 언어 이름을 그 언어 발음으로 읽어요 |

참고: Smashing Magazine "Designing A Perfect Language Selector UX"(2022), UX Planet "What is wrong with flag icons for languages".

검사는 세 언어, 화면 크기 일곱 가지(폰 세로 둘, 폰 가로 둘, 태블릿, 컴퓨터 둘), 두 화면에서 버튼이 다른 요소와 겹치지 않는지, 메뉴가 화면 밖으로 나가지 않는지, 키보드로 열고 닫히는지 봤어요(2026-11-13). 폰 세로에서 버튼이 로고에 겹쳐 첫 화면 위 여백을 늘렸어요.

## 문구를 고치거나 더할 때

- 세 언어에 같은 키를 넣어요. 빠진 키는 한국어로 나와요
- 값이 이름이나 숫자를 받으면 함수로 써요: `roomOf: n => \`${n} 님의 방\``
- 문서에 박힌 문구는 `client/shell.html` 에 한국어로 두고 `data-t` 를 붙여요. 굵은 글씨나 줄바꿈이 있으면 `data-th`, 읽어 주는 이름은 `data-ta`, 그림 설명은 `data-talt`
- 코드에서는 `tt("키")` 로 불러요. 전역 `t` 는 다른 함수의 시간 변수와 겹쳐서 쓰지 않아요
- 넣기 전에 Codex 로 다듬고 판정 심사를 받아요(`docs/conventions.md`). 영어 버튼은 짧게, 일본어 숫자는 반각

## 서버가 보내는 말

- 서버는 언어를 몰라요. 오류는 코드(`full`, `noRoom` 같은)로 보내고 화면이 그 언어로 바꿔요
- 봇 이름(도둥이, 냥파 같은)과 이름을 비운 사람(참가자)은 서버가 한국어로 붙여요. 화면이 `nameOf()` 로 바꾸고, 사람이 정한 이름은 그대로 둬요
- 대기실의 정해진 말은 번호로 주고받아요. 같은 방에서도 각자 자기 언어로 보여요
- 점검 안내에 어드민이 적은 말은 한국어라, 다른 언어 화면에서는 정해진 안내만 보여 줘요
