# 혼자 하기 시작 화면

첫 화면의 "혼자 해 보기"나 열쇠 없이 처음 열었을 때 나와요. 팀, 난이도, 지도를 고르고 시작해요. 코드는 `client/solo.js`, 문구는 `client/i18n.js` 의 `solo`.

## 정한 것

| 결정 | 이유 |
| --- | --- |
| 고른 뒤 "○○로 시작하기"를 눌러 시작해요(예전에는 팀 카드를 누르면 바로 시작) | 난이도와 지도를 고르기 전에 판이 시작되는 일이 없어요. 시작 버튼이 고른 편 이름과 색을 말해서 무엇으로 시작하는지 보여요 |
| 팀은 처음에 고르지 않은 상태, 전에 고른 것만 기억 | 두 편은 대등하다(`AGENTS.md`). 처음 온 사람에게 한쪽을 미리 골라 두지 않아요. 고른 편, 난이도, 지도는 `localStorage` 의 `solo:` 에 남아 다음에 그대로 열려요 |
| 팀 카드는 게임 캐릭터 고르기처럼 큰 그림, 고르면 편 색 테두리, 체크, 그림이 한 번 뛰어요 | 고른 상태를 색 하나에 기대지 않고(테두리, 체크, 다른 편 그림이 흐려짐) 보여요. 두 카드는 같은 크기예요 |
| 난이도는 막대 수와 한 줄 설명 | "쉬움, 보통, 어려움" 말만으로는 무엇이 다른지 몰라요. 실제로 바뀌는 것(봇이 반응하는 빠르기, 보는 거리)만 말해요(`shared/logic.js` `DIFF`) |
| 지도는 위에서 본 작은 그림과 이름 | 이름만 보고 떠올리게 하지 않고 알아보게 해요(Nielsen 휴리스틱 "기억보다 알아보기") |
| 고른 지도가 옆(폰 세로는 위)에 실제 게임 그림으로 천천히 지나가요. 그 지도 그대로 판이 시작돼요 | 어떤 지도인지 직접 보여 줘요. 미리보기와 판은 같은 씨앗과 같은 값(편, 난이도에 따른 지도 크기)으로 만들어 보이는 대로 해요. "다른 지도"로 같은 테마의 다른 지도를 뽑아요 |
| 지도 특징 한 줄은 테마 값에서 나온 것만 | 밤 골목은 시야가 짧고, 공원은 건물이 적고 수풀이 많고, 도심은 그 반대, 눈 마을은 시야가 조금 짧아요(`THEMES` 의 `vision`, `cover`, `bush`) |
| 랜덤은 미리보기가 테마를 돌아가며 보여 줘요 | 무엇이 나올지 모르는 재미를 그대로 두되, 어떤 지도들이 있는지는 보여 줘요 |
| 규칙은 "규칙 한눈에 보기"로 접어 두고, 자세한 것은 "게임 방법" | 고르는 화면을 가볍게 해요. 문구에는 초를 적지 않아요(`docs/guide.md`) |
| 화면 나누기: 넓은 화면은 왼쪽 고르는 칸, 폰 가로는 오른쪽 고르는 칸(시작 버튼이 오른손 엄지 자리), 폰 세로는 위 지도, 아래 고르는 칸 | 게임 방법 안내와 같은 배치예요(사용자 판단, 2026-11-13). 시작 버튼은 칸 아래에 붙어 늘 보여요 |
| 낮은 화면(폰 가로)은 팀을 가로 카드, 난이도를 한 줄, 지도를 여섯 칸 한 줄로 | 스크롤 없이 한 화면에 들어와요 |
| 같은 줄에서는 화살표로 옮겨요(라디오 묶음) | 키보드로도 고를 수 있어요 |
| 폰에서 첫 화면 버튼으로 들어오면 전체 화면 | 주소창이 지도를 가려 거슬렸어요(사용자 판단, 2026-11-13). 브라우저는 누른 순간에만 허락해서 "혼자 해 보기"를 누를 때 요청하고, 처음 화면으로 나가면 풀어요. 아이폰 사파리는 전체 화면을 지원하지 않아 그대로예요 |
| 폰은 나가기를 지도 위 왼쪽 위에 띄워요 | 고르는 칸 안에 두면 설정을 내렸을 때 같이 올라가 사라져요. 떠 있으면 스크롤과 상관없이 바로 나가요(사용자 판단). 넓은 화면은 칸 머리의 뒤로 버튼 |

## 확인

컴퓨터(1280x800, 1280x620), 폰 가로(844x390, 667x375), 폰 세로(390x844), 세 언어에서 시작 버튼이 늘 보이는지, 고른 편·난이도·지도로 시작하는지, 미리보기 지도와 판 지도가 같은지(지도 크기, 건물 수) 확인했어요(2026-11-13). 게임 방법을 열었다 닫으면 고르던 화면과 미리보기로 돌아와요.
