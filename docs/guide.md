# 게임 방법 안내

첫 화면과 초대받아 들어온 화면의 "게임 방법" 버튼으로 열어요. 실제 게임 엔진으로 짧은 장면 여섯 개를 연기시키고, 옆에 한 장면씩 설명을 붙여요. 코드는 `client/guide.js`, 문구는 `client/i18n.js` 의 `guide`, `guideCopy`.

## 정한 것

| 결정 | 이유 |
| --- | --- |
| 영상 파일 대신 게임 엔진으로 연기 | 지도, 캐릭터, 시야, 노란 표시, 빨간 표시, 감옥, 화면 위 표시가 실제와 같아요. 영상은 언어마다, 폰과 컴퓨터마다 따로 찍어야 하고 화면이 바뀌면 낡아요. 파일 크기도 늘지 않아요 |
| 사람 입력 자리에 대본을 넣어요(`driver`) | 규칙은 `shared/logic.js` 그대로 돌아요. 잡기, 감옥, 문 열림, 공개가 실제 판정으로 일어나요 |
| 장면 여섯 개: 이기는 법, 움직이기와 달리기, 보이는 범위와 수풀, 잡기, 빨간 표시, 감옥 문 열기 | 해 보면 아는 것(걷기)은 짧게, 해 봐도 모르는 것(수풀, 빨간 표시, 감옥)에 장면을 써요(Andersen 외, CHI 2012, 아래 `docs/tutorial.md` 근거) |
| 화면을 둘로 나눠요. 게임 화면을 남은 자리 크기로 다시 맞춰요 | 설명이 게임 위에 떠 있으면 폰에서 글이 잘리고 조이스틱과 버튼을 가렸어요(첫 시안). 나누면 글은 다 보이고 게임 화면 안의 버튼은 제자리에 있어요 |
| 넓은 화면은 왼쪽에 여섯 장면 목록과 설명 | 넓은 화면에서는 문서 목차처럼 왼쪽 목록이 익숙하고, 원하는 장면으로 바로 가요 |
| 폰 가로는 오른쪽 설명 | "다음"을 누르는 손이 대개 오른손 엄지예요. 왼쪽 장면을 보고 오른쪽 설명을 읽는 순서와도 맞아요(사용자 판단, 2026-11-13) |
| 폰 세로는 위 장면, 아래 설명 | 세로에서는 아래쪽이 엄지가 닿는 자리예요(Hoober, 2013, "How Do Users Really Hold Mobile Devices?") |
| 폰은 손가락, 컴퓨터는 키가 눌려요 | 각자 쓰는 조작으로 보여 줘요. 손가락 표시는 버튼 글자를 가리지 않게 속이 빈 고리로 조금 아래에 둬요 |
| 장면은 되풀이하고, 저절로 넘어가지 않아요. 멈추기 버튼 | 읽는 속도가 사람마다 달라요. 5초 넘게 움직이는 내용은 멈출 수 있어야 해요(WCAG 2.2.2) |
| 문구에 정확한 초를 적지 않아요 | "35초마다", "3초 동안" 대신 "때때로", "잠깐"처럼 다른 게임들이 쓰는 말로 써요. 규칙 용어(구역, 위치 공개, 구출) 대신 화면에 보이는 것(빨간 점선, 빨간 표시, 감옥 문 앞)으로 써요(사용자 판단, 2026-11-13). 판 중에 줄어드는 숫자는 그대로 둬요 |
| 키보드: 화살표로 장면 이동, Esc 로 닫기, 닫으면 연 버튼으로 초점이 돌아가요 | 모달 대화상자 방식(W3C APG Dialog) |

## 장면 대본

모든 장면이 같은 동네 지도(`MAP`)를 써요. 가운데 큰길과 세로 길, 왼쪽 아래 감옥, 길가 수풀. 내가 맡는 편과 카메라가 볼 곳은 장면마다 정해요.

| 장면 | 나 | 보여 주는 것 |
| --- | --- | --- |
| 이기는 법 | 도둑 | 경찰이 감옥 앞에서 기다리는 동안 도둑 셋이 흩어지고, 시간이 되면 "경찰이 출동했어요" |
| 움직이기 | 경찰 | 걷다가 달리고, 아래 막대가 줄어 다 닳으면 달리기가 멈춰요 |
| 수풀 | 경찰 | 길에서는 수풀 속 도둑이 안 보이다가, 도둑이 뛰어나오는 순간 보여요 |
| 잡기 | 경찰 | 쫓아가면 도둑 발밑에 노란 표시가 뜨고, 잡기로 잡아요 |
| 빨간 표시 | 경찰 | 건물 뒤에 숨은 도둑 자리가 지도와 작은 지도에 빨갛게 떠서 그쪽으로 달려가요 |
| 감옥 문 | 도둑 | 감옥 문 앞에 서면 문이 열리고, 갇혀 있던 둘이 보호받으며 뛰어나가요 |

대본은 사람마다 가고 싶은 곳(`toward`)만 정하고, 걷기, 부딪힘, 잡기, 감옥은 규칙 파일이 처리해요. 나 말고는 `isPlayer` 로 두어 봇 생각을 건너뛰어요. 장면을 바꾸거나 닫으면 판 설정(`CFG`)을 원래대로 돌려놓아요.

## 시안 보기

`play.html?guide=1` 로 열면 바로 안내가 떠요. 화면 크기별 찍기는 언어, 크기(컴퓨터, 폰 가로, 폰 세로)마다 장면을 넘겨 찍어 확인했어요(2026-11-13).

## 같이 고친 것

- 대기실에서 달리기 버튼이 `display:block` 으로 덮여 발바닥과 글자가 어긋났어요. 대기실도 게임처럼 세로로 쌓아요(`client/lobby.css`)
- 폰 세로에서 남은 시간 칸이 소리 버튼 아래에 깔렸어요. 소리 버튼 옆에서 시작해요
