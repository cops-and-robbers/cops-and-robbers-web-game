# 수치 바꾸기

수치는 `shared/logic.js` 의 `CFG`, `DIFF` 에 있어요.

1. 무엇이 왜 문제인지 한 줄로 적어요. 사람이 해 본 말을 먼저 봐요. 예: "경찰 사거리가 너무 짧다"
2. 한 번에 한 값만 바꿔요.
3. 바꾸기 전후로 `node tools/sim.mjs 60` 을 돌려 승률, 판 길이, 체포 수, 쫓는 장면 수를 견줘요.
4. `pnpm run check:map` 으로 지도 검사도 봐요.

## 판단 기준

- 판 수가 적으면 오차가 커요. 20판이면 ±20%쯤, 60판이면 ±13%쯤이에요. 그 안의 차이로 결론 내지 않아요
- 봇은 사람과 달라요. 봇 승률이 비슷해도 사람에게는 한쪽이 어려울 수 있어요. 마지막 판단은 사람끼리 해 본 결과로 해요
- 경찰과 도둑은 대등해요. 한쪽만 올리면 다른 쪽이 어떻게 되는지 함께 봐요
- PR 에 전후 숫자와 판 수를 적어요
